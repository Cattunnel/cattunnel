# CatTunnel

CatTunnel: клиент VPN для Android, Windows и Linux. Он подключается к серверам по протоколу TrustTunnel (TLS и HTTP/2 или HTTP/3) и к [серверу CatTunnel](https://github.com/Cattunnel/cattunnel-server) с транспортом NineLives. Серверов и подписок проект не предоставляет: нужен свой сервер или сервер от администратора.

## Репозитории CatTunnel

| Репозиторий | Что это |
|---|---|
| [Cattunnel/cattunnel](https://github.com/Cattunnel/cattunnel) | Приложение для Android, Windows и Linux (этот репозиторий) |
| [Cattunnel/cattunnel-router](https://github.com/Cattunnel/cattunnel-router) | Роутерная редакция для OpenWrt, Keenetic и ASUS Merlin |
| [Cattunnel/cattunnel-server](https://github.com/Cattunnel/cattunnel-server) | Сервер: форк TrustTunnel endpoint с транспортом NineLives |

В основе приложения открытый [TrustTunnel Flutter Client](https://github.com/TrustTunnel/TrustTunnelFlutterClient) (Apache-2.0). CatTunnel добавляет собственную сборку сетевого ядра, подписки с шифрованием age, пошаговую диагностику подключения, строгую проверку сертификатов и русский интерфейс. В приложении есть кот-помощник Марсик: он объясняет, что пошло не так.

> Аккаунт создан отдельно от автора, и это сделано сознательно: проект разрабатывался закрыто с сентября 2026 года, а публичным стал в октябре без привязки к личности разработчика. По той же причине история разработки до публикации не перенесена, и репозиторий начинается с уже готового кода. Все сборки CatTunnel публикуются только в разделе релизов этого репозитория, а файлы с других сайтов к проекту отношения не имеют.

## Возможности

### Подключение и серверы

- Серверы вручную, по ссылке `tt://`, по QR-коду или из подписки. Новая ссылка на тот же аккаунт (тот же домен, логин и ключ) обновляет сервер, например «порт 8443 → 9443», и сохраняет имя и роутинг вместо дубля.
- Kill switch, автоподключение, кнопка в шторке Android: включает VPN без открытия приложения, в том числе на Samsung, который сбрасывает разрешение VPN после каждой остановки.
- **Ротация IP** (1.5.9.5): один ключ работает через несколько серверов по очереди и переходит на следующий через случайное время. Отказавший сервер отдыхает, туннель при этом не рвётся. Подробно: [docs/rotation.md](docs/rotation.md).
- Переход на другой сервер той же подписки, если выбранный не подключается 2 минуты, и попытка вернуться потом. Выключается в настройках.
- Серверы идут в порядке подписки, любимые отмечаются звёздочкой и стоят сверху; подписки и свои ключи собраны в группы, которые можно переставлять и переименовывать. Пинг рядом с ключом берётся из самого подключения.
- Работающий VPN не переподключается при повторном открытии приложения; смена сервера: одно подключение, а не два.
- Проверка и сортировка серверов по задержке, настройка MTU.
- Ключи «Российский выход» для тех, кто за границей: через сервер идут только российские сайты и приложения, остальное напрямую.
- Статистика трафика на Android, Windows и Linux: графики за 24 часа - 90 дней по серверам, часам и дням недели, тепловая карта, лимит в месяц. Считается только на устройстве.

### Подписки

- Подписка сама обновляет список серверов и их настройки. Только `https://`, без перенаправлений, с запасными адресами (зеркалами) на случай блокировки первого.
- **Ключ устройства.** Приложение создаёт свой ключ age (X25519) и не меняет его; закрытая часть остаётся на устройстве, серверу уходит открытая, и ответ шифруется под неё. Утёкший адрес подписки другому устройству ничего не даёт. Поддерживаются бинарный формат age и ASCII armor.
- **Подписка главнее ключа.** При каждом обновлении подписка записывает в свои ключи все значения ссылки, включая выключенные. Свои настройки ключа включаются переключателем «Выше подписки», кнопка «Вернуть как на сервере» возвращает серверные.
- Под подпиской видно, как прошёл последний опрос: через какой адрес и за сколько, или сколько адресов не ответили и почему. Токен подписки при этом не записывается.
- Обмен подпиской через QR-код, импорт сканером или с картинки («Из галереи»), одноразовые коды из браузера.

Формат, заголовки запроса и правила обновления: [docs/subscriptions.md](docs/subscriptions.md).

### Устойчивость к DPI

- **Анти-DPI.** Своя сборка ядра TrustTunnelClient отправляет ClientHello приёмами из [ByeDPI](https://github.com/hufrea/byedpi): «срочный» байт, кусок с TTL 1, разрыв внутри имени сервера. Способы 1-3, своя строка в синтаксисе ByeDPI и режим «Авто»: сначала обычное соединение, потом способы по очереди; удачный способ для сервера и сети запоминается до конца дня. Автоматический обход по умолчанию выключен: для ключей из подписок он включается до конца дня, для личных ключей остаётся включённым; если подписка задаёт обход своим ключам, решает она. Подробно: [docs/anti-dpi.md](docs/anti-dpi.md).
- **Список «Сети»** («Настройки → Сети»): сети, где обычное соединение сегодня перерезано и приложение включает обход. Сеть помечается, только если потом сработал способ обхода. Там же «Проверить сеть»: проверка своих серверов подписки по кнопке.
- **Отпечаток TLS** для каждого сервера: по умолчанию как у браузера устройства, на выбор Chrome 150, Chrome 156, Firefox, Safari и приложение Android.
- **Маскировка размеров (HTTP/2 padding).** Первые кадры каждого потока получают случайные байты в пределах бюджета на поток и на сессию; сервер ничего не настраивает. Подробно: [docs/padding.md](docs/padding.md).
- **Пул соединений.** Соединения приложений идут через 2-4 TLS-соединения с сервером, новые открываются с паузой 2-6 с, а не залпом.
- **Имя сервера и профиль от подписки.** Подписка может выдать ключу своё имя сервера (SNI) и профиль TLS и менять их; приложение берёт значения из последнего обновления.
- **NineLives** («Для экспертов», нужен [сервер CatTunnel](https://github.com/Cattunnel/cattunnel-server) или другой с его поддержкой): пара запросов GET и POST вместо CONNECT, своё шифрование тела внутри TLS по ключу сервера, продолжение сессии после обрыва до 60 секунд. С XHTTP из Xray не совместим. Подробно: [docs/ninelives.md](docs/ninelives.md).
- **Отключение QUIC** внутри туннеля: браузеры переходят на TCP.
- Понятные причины отказа и бережные повторы, если фильтр временно «заморозил» адрес сервера.

### Раздельное туннелирование

- Сайты, IP-адреса, сети и приложения мимо VPN; свой список редактируется.
- **Приложения на Windows и Linux** (с 1.5.6, без драйвера): мимо VPN или только через VPN идут соединения выбранных программ. Ядро находит владельца сокета (Windows: `GetExtendedTcpTable`/`GetExtendedUdpTable`, Linux: `NETLINK_SOCK_DIAG`).
  *DNS разделяется не везде.* На Windows и на Linux с systemd-resolved имена за программы разрешает система, поэтому запросы исключённой программы идут через DNS туннеля: утечки к провайдеру нет, но адрес сайта подбирается под страну сервера, а без туннеля исключённая программа остаётся без DNS. Чтобы DNS тоже шёл мимо, включите в такой программе её собственный DNS («Безопасный DNS» в Chrome или DoH в Firefox). На Linux без systemd-resolved программа спрашивает DNS сама, и её запросы уходят мимо туннеля вместе с остальным трафиком, как на Android.
- Российские сети и домены подтягиваются автоматически (runetfreedom, ipverse, hydraponique) и обновляются раз в сутки.
- Режим «Авто»: российские, китайские и узбекские сервисы и приложения производителя телефона мимо VPN; российские всегда, остальные можно вернуть в туннель.
- **Яндекс Браузер всегда остаётся в VPN**, хотя он российский: у многих это основной браузер, и иначе мимо туннеля уходил бы почти весь их трафик. Сайты Яндекса при этом всё равно идут напрямую по правилам доменов.
- Скачанные списки проверяются на правдоподобие: правило вроде `0.0.0.0/0` («всё мимо VPN») отбрасывается, при подозрительной загрузке остаётся прошлая копия. Адрес самого VPN-сервера из списков всегда вычитается.

### Диагностика: кот Марсик

- Если подключение зависло на 10 секунд, Марсик проверяет сеть, доступность сервера, защищённое соединение, ключи и подписку, одной строкой говорит, что не так, и предлагает одно действие. Проверки идут только к вашим серверам.
- Если система не дала создать VPN, он говорит об этом прямо.
- «Сообщить о проблеме»: отчёт для администратора без паролей, ключей и аппаратных адресов; на Windows и Linux он сохраняется в «Загрузки» и копируется в буфер обмена.
- Марсика можно гладить: комплименты, счётчик, пасхалки, мурлыканье и иногда стихи.

### Безопасность и приватность

- **Строгая проверка сертификата сервера** (включена по умолчанию на Android, Windows и Linux): только системные корневые сертификаты, без «Russian Trusted Root/Sub CA» (по имени и по отпечатку ключа) и вручную установленных. Выключить можно только после трёх подтверждений.
- Ссылка или файл сервера от другого человека не включают «Российский выход» сами; невидимые символы и символы смены направления текста в именах серверов убираются; ответы подписки, обновлений и списков ограничены по размеру.
- Проверка устройства и утечек, тревожная кнопка (стереть данные приложения), маскировка под «Калькулятор», блокировка приложения, защита экранов с ключами от скриншотов.
- Нет аналитики и рекламы, телеметрия ML Kit отключена; данные не попадают в облачные резервные копии; пароли, ключи и адреса подписок не пишутся в журнал.

Подробнее: [docs/security/](docs/security/).

### Компьютеры

- **Linux:** пакеты Arch и Debian; приложение работает от пользователя, права root только у помощника с белым списком команд и закалённым systemd-юнитом.
- **Windows:** установщик и обновления из приложения; значок в трее, крестик прячет окно в трей.
- **Значок в трее на Linux** на Dart через D-Bus (StatusNotifierItem), без новых системных библиотек: KDE, XFCE, Cinnamon, MATE, Ubuntu.

### Оформление и обновления

- Пять стилей главного экрана, выбор листанием превью: «Уютный», «Минимализм», «Y2K», «Аэро» и «City pop». На планшетах приложение поворачивается. Тёмная тема, окно «Что нового», обучение при первом запуске, русский и английский интерфейс.
- Android и Windows обновляются из приложения: `latest.json` подписан Ed25519, файлы сверяются по SHA-256, адрес обновлений задаётся только при сборке.

### Проверка подлинности

Файлы релиза перечислены в `SHA256SUMS`, подписанном ключом Ed25519. Публичный ключ: [`linux/packaging/cattunnel-release.pub.pem`](linux/packaging/cattunnel-release.pub.pem).

```bash
openssl pkeyutl -verify -pubin -inkey cattunnel-release.pub.pem -rawin \
  -in SHA256SUMS -sigfile <(base64 -d SHA256SUMS.sig)
sha256sum -c SHA256SUMS --ignore-missing
```

Сертификат подписи Android-приложения: `CN=CatTunnel`, SHA-256 `42:6C:CE:9A:C6:62:B2:D1:41:01:E2:7F:0C:B6:7E:0C:AA:23:13:7B:CC:29:1C:6D:6A:06:EF:11:62:99:AF:B7`.

## Настройка

1. Добавьте сервер: «Добавить сервер», затем ссылка `tt://`, QR-код (кнопка «Из галереи» читает QR с картинки) или ручной ввод. Ссылку `tt://` печатает сервер командой экспорта (`trusttunnel_endpoint … -c <пользователь> -a <адрес>`, см. [README сервера](https://github.com/Cattunnel/cattunnel-server#export-a-client-configuration)).
2. Или добавьте подписку: «Добавить сервер» → «Подписка», адрес `https://` или одноразовый код от администратора. Подписка сама создаст серверы и будет их обновлять.
3. Нажмите «Подключить». Если не подключилось за 10 секунд, Марсик покажет причину.

Анти-DPI и отпечаток TLS находятся в настройках сервера, раздел «Обход блокировок»; маскировка размеров, отключение QUIC, keepalive и NineLives в разделе «Для экспертов». Ключи из подписки подписка перезаписывает при каждом обновлении, пока не включён переключатель «Выше подписки». Подробное руководство: [assets/readme/README.ru.md](assets/readme/README.ru.md), как устроено подключение: [assets/readme/CONNECTION.ru.md](assets/readme/CONNECTION.ru.md).

## Сборка из исходников

**Требования:** Flutter **3.38.3** (версия зафиксирована в `pubspec.yaml`), JDK 17, Android SDK (platform 36), NDK `29.0.14206865`, токен GitHub с правом `read:packages`: Android-движок TrustTunnel загружается из GitHub Packages.

```bash
export GPR_KEY=<токен с read:packages>
make init          # зависимости и генерация кода
flutter test
```

**Android**

```bash
# Основная сборка (arm64)
flutter build apk --release --split-per-abi --target-platform android-arm64

# Универсальная (arm64 + armv7), с тем же versionCode, что у arm64
flutter build apk --release --target-platform android-arm,android-arm64 --build-number=<versionCode arm64>

# Обновления из приложения: адрес latest.json и ключ, которым он подписан
flutter build apk ... \
  --dart-define=UPDATE_URL=https://github.com/Cattunnel/cattunnel/releases/latest/download/latest.json \
  --dart-define=UPDATE_PUBKEY=$(openssl pkey -pubin -in linux/packaging/cattunnel-release.pub.pem -outform DER | tail -c 32 | base64)

# Свой идентификатор приложения (форк, параллельная установка)
ORG_GRADLE_PROJECT_appId=org.example.myvpn flutter build apk ...
```

Релизная подпись берётся из `android/key.properties` и `android/keystore/` (оба пути в `.gitignore`). Без них сборка подписывается отладочным ключом, и такой APK не встанет поверх официального.

**Windows и Linux:** установщик в [`windows/installer/`](windows/installer/), пакеты Arch и Debian в [`linux/packaging/`](linux/packaging/README.md).

**Сетевое ядро:** собственная сборка TrustTunnelClient с патчами CatTunnel, скрипты и патчи в [`tools/engine_native/`](tools/engine_native/README.md), патчи Android-движка в [`tools/engine_patch/`](tools/engine_patch/). Патчи в этих папках описывают ядро 1.3.0-rc.1 с анти-DPI, причинами отказа, первой версией маскировки размеров, отключением QUIC и сплитом по программам. В 1.5.9 приложение на всех платформах и роутер собраны из одной ревизии ядра (`82963908`); её изменения сверх этих патчей (пул соединений, NineLives, формирователь набивки, браузерные заголовки `CONNECT`) в эту папку пока не выложены.

<details>
<summary>Заметки по сборке</summary>

- `--split-per-abi` прибавляет 2000 к `versionCode` для arm64, поэтому универсальной сборке номер передаётся явно.
- Библиотеки x86/x86_64 исключены из APK: на x86-эмуляторах приложение не запустится.
- `tools/update_engine.sh <версия>` меняет версию ядра сразу для всех платформ.
- `latest.json` для релиза: `tools/make_latest_json.sh https://github.com/Cattunnel/cattunnel/releases/download/v<версия> <arm64.apk> <universal.apk> notes.txt`, подпись: `tools/sign_latest_json.sh`.
- Изменения оригинального TrustTunnel Flutter Client переносятся по одному (cherry-pick): история этого репозитория начинается заново, общего предка с upstream нет.

</details>

## Структура

```text
lib/                      приложение (Flutter)
  feature/companion/      Марсик
  feature/vpn/domain/     диагностика, анти-DPI «Авто», отпечаток TLS
  feature/security/       проверки устройства и утечек, тревожная кнопка
  feature/subscriptions/  подписки, QR, импорт
plugins/vpn_plugin/       привязки к TrustTunnelClient (Pigeon);
                          linux/helper: привилегированный помощник
packages/dage/            библиотека age с исправлениями совместимости
tools/engine_native/      сборка своего ядра и патч анти-DPI
tools/engine_patch/       патчи Android-движка
android/ ios/ macos/ windows/ linux/   платформенные части, установщик и пакеты
docs/                     устройство, подписки, анти-DPI, padding,
                          NineLives, ротация IP, безопасность
test/                     тесты (flutter test)
```
