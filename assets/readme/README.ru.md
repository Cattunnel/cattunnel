# CatTunnel

VPN-клиент для Android на протоколе **TrustTunnel** — ответвление открытого клиента TrustTunnel (лицензия Apache-2.0). Талисман и помощник — кот **Марсик**.

## Быстрый старт

1. Получи подписку у администратора VPN (например, в боте: `/config` → Android → «Подписка»). Там будут ссылка и ключ шифрования.
2. «Добавить сервер» → «Подписка» → вставь ссылку и ключ. Или отсканируй QR подписки (см. ниже).
3. Выбери сервер и нажми «Подключить» — или большую кнопку с Марсиком, если выбран стиль «Уютный».

## Серверы и подписки

- **Способы добавить сервер:** вручную, ссылкой `tt://`, по QR-коду или через подписку.
- **Подписка** — адрес, по которому приложение получает список твоих серверов. Принимаются только адреса `https://`; перенаправления на другие адреса запрещены.
- **Шифрование подписки (age).** Если в подписке указан ключ `AGE-SECRET-KEY-1…`, ответ сервера расшифровывается прямо на телефоне — перехватившему ссылку по пути виден только шифр. Поддерживается и бинарный формат age, и текстовый («armor»).
- **Автообновление:** раз в сутки перед подключением (ждём не дольше 4 секунд, при неудаче — повтор не раньше чем через час). Обновить вручную можно кнопкой у подписки.
- Если подписка вернула пустой список, серверы **не удаляются** — это почти всегда ошибка на стороне сервера.
- **Запасные адреса подписки.** Сервер присылает вместе со списком серверов несколько адресов, по которым её можно скачать. Если первый недоступен (например, заблокирован у твоего оператора), приложение само пробует следующий.
- **Поделиться подпиской:** меню «⋮» у подписки → «Поделиться через QR». Код — это полный доступ к твоим серверам: показывай его только своим устройствам и людям, которым доверяешь.
- **Импорт по QR:** «Добавить сервер» → QR-код. Сканер узнаёт и сервер, и подписку; сохранение всегда подтверждаешь ты.
- **Экспорт сервера** (QR и ссылка) и эти экраны защищены от скриншотов и записи экрана.

## Подключение

- **Кнопка в шторке.** Включает и выключает VPN. Если VPN был выключен вручную, кнопка открывает приложение, и оно сразу подключается к последнему серверу.
- **Автоподключение при запуске**, **Kill switch** (блокировка трафика при обрыве), **Российские сервисы напрямую** (банки, Госуслуги и т.п. идут мимо VPN; список редактируется), MTU, таймаут проверки серверов — в «Настройки → Запуск и подключение».
- **Одно уведомление** «CatTunnel — подключено к …» вместо двух.
- **Анти-DPI** и другие настройки обхода — в настройках сервера, раздел «Обход блокировок» (у каждого раздела есть «?» с пояснением). Способы: «Обычный», 1, 2, 3 (приёмы из ByeDPI), «Авто» (пробует 1 → 2 → 3 и запоминает удачный для сервера и сети) и «Своя строка» в синтаксисе ByeDPI. Там же отпечаток TLS; в «Для экспертов» — маскировка размеров и «Отключить QUIC» (UDP на порт 443 не пропускается, браузеры идут по TCP внутри туннеля). Подписка может выбрать всё это сама. Как это работает по шагам — «Настройки → Как устроено подключение».
- Для надёжности включи в настройках Android для CatTunnel «Постоянная VPN» и «Блокировать соединения без VPN».

## Сплит-туннель

Вкладка «Роутинг» — окно «Сплит-туннель» открывается само:
- **Сайты и IP** — домены и адреса, которые идут напрямую, мимо VPN. Включи «Российские сервисы» — и российские сети подтянутся автоматически из открытых списков (runetfreedom, ipverse, hydraponique), обновляются примерно раз в сутки.
- **Приложения** — все через VPN; выбранные мимо VPN; или только выбранные через VPN. «Авто: российские и китайские мимо VPN» (включено по умолчанию) — банки, Госуслуги, маркетплейсы, VK, Яндекс, китайские сервисы и приложения производителя телефона идут напрямую; список пересчитывается при каждом подключении. Исключение — **Яндекс Браузер**: он всегда остаётся в VPN, потому что у многих это основной браузер (сайты Яндекса всё равно идут напрямую по доменам).
- Изменения применяются при следующем подключении.
- **Телефоны vivo, OPPO, realme, OnePlus, iQOO (BBK).** Когда включены «Российские сервисы», прошивка этих телефонов может писать «VPN не подключён» или «нет интернета», хотя всё работает: Android не отмечает VPN с большим списком маршрутов как проверенный. Марсик один раз скажет об этом сам, а потом рядом с «Подключено» появится кнопка «i».

## Обновления

- **Сами, внутри приложения.** Вскоре после запуска (не чаще раза в сутки) CatTunnel проверяет, вышла ли новая версия, и Марсик предлагает обновиться: одна кнопка — скачать и установить. Проверить вручную: «Настройки → О приложении → Проверить обновления».
- В первый раз Android попросит разрешить CatTunnel **устанавливать приложения** — это нужно только для обновлений.
- **Google Play Protect** может предложить «проверить приложение», потому что CatTunnel нет в Google Play: нажми «Подробнее» → «Установить без проверки».
- **Подменить обновление нельзя:** файл сверяется по контрольной сумме, а Android ставит обновление только с той же подписью, что у установленного приложения.

## Оформление

«Настройки → Оформление»:
- **Стиль «Уютный»** — на главном экране большая круглая кнопка с Марсиком (спит, когда VPN выключен; держит щит, когда включён), под ней статус, время сеанса, пинг и карточка сервера. Нажми на карточку — откроется список серверов с кнопкой «Проверить все».
- **Стиль «Минимализм»** — привычный список серверов с кнопками включения.
- **Тема:** как на телефоне, светлая или тёмная.
- После обновления приложение один раз покажет «Что нового» и спросит, какой главный экран тебе больше нравится.

## Марсик

- **Диагностика.** Если подключение висит 10 секунд, Марсик сам проверяет по шагам: есть ли интернет → отвечает ли сервер → проходит ли защищённое соединение (и не режут ли по имени сервера, SNI) → принимает ли сервер ключи и жива ли подписка. Он скажет, что не так, и предложит сервер, который сейчас работает.
- **Погладить.** Кнопка с котом на главном экране (в обоих стилях): гладь пальцем — заполняется шкала, за полную шкалу Марсик говорит комплимент. Есть счётчик поглаживаний, пасхалки и мурлыканье (по умолчанию выключено, включается значком динамика).

## Кибербезопасность

Раздел «Настройки → Кибербезопасность».

- **Проверка телефона:** сертификат Минцифры и другие установленные вручную сертификаты, блокировка экрана, частный DNS, отладка по USB, ограничения работы в фоне, утечка IPv6. У каждой находки — кнопка «Исправить».
- **Проверка утечек:** адрес, с которого трафик выходит через VPN, и твой настоящий адрес; DNS внутри VPN; утечка IPv6. Кнопка «Проверить в браузере» открывает ipleak.net — там видны утечки DNS и WebRTC в браузере.
- **Строгая проверка сертификата сервера** — по умолчанию **включена**. Сертификат Минцифры («Russian Trusted Root CA») ставится вручную, обычно ради банков. Если бы VPN ему доверял, владелец этого сертификата мог бы подменить сертификат сервера и расшифровать туннель вместе с логином и паролем. Пока проверка включена, VPN проверяет сервер только по системным сертификатам Android, без сертификата Минцифры. Серверы со своим сертификатом (PEM) проверяются только по нему. Выключать — лишь если VPN из-за неё не подключается или провайдер попросил установить его сертификат. Выключение — после трёх подтверждений.
- **Тревожная кнопка** (по желанию): долгое нажатие на Марсика на экране серверов → подтверждение → стираются все серверы, подписки, ключи, настройки и логи, приложение закрывается. Вернуть можно только заново через подписку.
- **Маскировка** (по желанию): иконка и название на рабочем столе — «Калькулятор», уведомление и плитка — тоже. Значок VPN в строке состояния и имя приложения в настройках Android не меняются — это защита от беглого взгляда, а не от проверки настроек.
- **Блокировка приложения** (по желанию): отпечаток, лицо или PIN телефона при открытии и после минуты в фоне. Нужна установленная блокировка экрана.

## Данные и приватность

- **Что хранится на телефоне:** серверы, логины и пароли, подписки и ключи age, настройки. Всё — во внутренней памяти приложения.
- **В резервные копии и перенос на новый телефон ничего не попадает** — на новом телефоне подписка восстанавливается за минуту.
- **Журнал соединений** (куда подключались приложения) хранится только в течение текущего сеанса и стирается при каждом отключении VPN и запуске приложения.
- **Логи** не содержат паролей, ключей и адресов подписки. Отправляются куда-либо только по твоей кнопке «Поделиться».
- **Аналитики и рекламы нет.** Телеметрия Google ML Kit (сканер QR) отключена.
- **Какие адреса приложение использует само:** твои серверы и адрес подписки; `ya.ru` и `77.88.8.8` — диагностика («есть ли интернет»); `1.1.1.1` (Cloudflare) — проверка утечек; ipleak.net — только по кнопке; сервер загрузок — проверка и скачивание обновлений (адрес задаётся при сборке; в запросе нет ничего о тебе, только скачивание файла с номером версии).

## Техническая информация

- **Версия:** 1.5.0. **Android:** 8.0 и новее (minSdk 26, targetSdk 36).
- **«/S-Signed» в версии** (например, `1.4.0/S-Signed`) — сборка, подписанная и выпущенная **после проверки на VirusTotal**. Сначала собирается та же сборка с обычной версией `1.4.0` и проверяется на VirusTotal, затем из того же кода — подписанная, со ссылкой на этот отчёт. Ссылка — в «Настройки → О приложении». Отчёт относится к «двойнику» без суффикса и без ссылки: ссылка не может указывать на файл, внутри которого лежит (она меняет его хэш).
- **Сборки:** `arm64` (основная, почти все телефоны) и универсальная `arm64 + armv7` (если основная не ставится).
- **Протокол:** TrustTunnel — HTTP/2 поверх TLS (QUIC поддерживается протоколом). Нативный движок — TrustTunnelClient 1.3.0-beta.1, собранный нами с патчами CatTunnel (см. «Чем отличается от TrustTunnel»).
- **Приложение исключено из собственного туннеля** — так устроен движок; поэтому диагностика и проверки работают и во время подключения.
- **Ссылка сервера:** `tt://?…` — base64url от набора полей TLV (адрес, имя хоста, логин, пароль, SNI, сертификат, DNS и др.; формат — DEEP_LINK.md проекта TrustTunnel).
- **Тело подписки:** ссылки `tt://`, по одной на строку; при наличии ключа — зашифровано age (X25519).
- **Ссылка подписки для QR:** `cattunnel://subscription?url=…&key=…&name=…`.
- **Проверка сертификата сервера:** свой сертификат сервера (PEM) → только он; иначе системные корневые сертификаты Android без «Russian Trusted Root/Sub CA»; пользовательские — только если строгая проверка выключена.
- **Разрешения:** интернет, VPN, уведомления, камера (сканер QR), биометрия (блокировка), работа в фоне (VPN-сервис), установка приложений (только обновления CatTunnel).
- **Лицензии:** Apache-2.0 (TrustTunnel). Звук мурлыканья — CC0 (freesound.org, запись 496275).

## Чем отличается от TrustTunnel

Всё ниже добавлено в этом ответвлении; в оригинальном клиенте TrustTunnel этого нет. Формат: что делает → как устроено → где в коде.

### Подписки
- **Подписки на список серверов** → тело ответа — ссылки `tt://` построчно, разбираются тем же декодером, что и одиночная ссылка; серверы сверяются по имени в пределах своей подписки (новые добавляются, пропавшие удаляются, выбранный сервер не удаляется никогда; одинаковые имена в одном ответе — берётся первое) → `lib/data/domain/subscription_sync_service.dart`, `subscription_datasource_impl.dart`, миграции базы v5/v6.
- **Защиты подписки** → только `https://`, без перенаправлений; пустой ответ считается ошибкой и не стирает серверы; автообновление перед подключением ждёт максимум 4 с, после неудачи час не повторяется (чтобы не копить 404 для fail2ban сервера) → там же и `servers_card.dart`.
- **Шифрование age** → ответ расшифровывается ключом X25519 на телефоне; принимаются бинарный и armor-формат. В пакете `dage` исправлены две ошибки совместимости со стандартом age (соль HKDF для MAC заголовка и формат «grease»-строф), пакет лежит в проекте → `packages/dage`, `lib/common/utils/age_armor.dart`.
- **Группировка серверов по подпискам**, ручное обновление, **QR для подписки** (`cattunnel://subscription?url&key&name`) и её импорт сканером → `subscription_servers_group.dart`, `subscription_share_link.dart`, `qr_scan_screen.dart`.

### Подключение
- **Плитка в шторке** → при сохранённом конфиге подключает без открытия приложения (конфиг, который нативный сервис хранит для Always-On); иначе открывает приложение со случайным секретом процесса, и оно подключается к последнему серверу; «включено ли» определяется по собственному сервису, а не по любому VPN → `CatTunnelQsTileService.kt`, `CatTunnelActivity.kt`, `auto_connect_on_launch_settings_scope.dart`.
- **Одно уведомление** → приложение публикует своё уведомление с номером и каналом обязательного уведомления нативного сервиса, и Android заменяет его на месте → `vpn_connection_notifier.dart`.
- **Kill switch, автоподключение и российские сервисы напрямую доступны на телефоне** (в оригинале экран был только для macOS), редактируемый список правил, MTU, таймаут проверки.

### Обновления и ядро
- **Обновления внутри приложения** → `latest.json` с сервера загрузок (адрес — только через `--dart-define=UPDATE_URL`, в исходниках его нет; без него функция выключена); сравнивается `build` (versionCode) → APK под архитектуру телефона в `cache/updates/` → sha256 проверяется в нативном коде → системный установщик через свой FileProvider → `lib/feature/updates`, `UpdateChannel.kt`, `tools/make_latest_json.sh`.
- **Патчи ядра (Android)** → Kotlin-часть движка пересобирается с патчами (нативная часть — наша сборка с патчем анти-DPI, `tools/engine_native`): `0001` — выбор приложений (`excluded_apps` / `included_apps`); `0002` — конфиг передаётся сервису в памяти, а не через Intent (со списками РФ он больше 1 МБ, лимит Binder); `0003` — если приложение просит запустить уже работающий VPN, движок сообщает ему настоящее состояние, и приложение не показывает рабочий VPN как сломанный; `0004` — на Android 13+ российские сети исключаются через `excludeRoute` (маршрутов — несколько десятков вместо сотен); `0005` — «Отключиться» всегда закрывает сервис, даже если подключение зависло; `0006` — если система не дала создать VPN (например, `Cannot set address`) или старт сорвался по другой причине, движок сообщает приложению «отключено», а не молчит → `tools/engine_patch`.
- **Одна версия ядра на все платформы** → файл `ENGINE_VERSION`, обновление одной командой `tools/update_engine.sh <версия>` (проверяет, что версия вышла, пишет хэши десктопных сборок в `ENGINE_SHA256`).

### Оформление
- **Тёмная тема и стили** → все цвета темы вынесены в палитру (`theme_palette.dart`: светлая — исходная, тёмная — от того же акцента `#3972AA`); стиль и тема хранятся в `appearance_preferences.dart`; «Уютный» главный экран → `lib/feature/server/servers/widget/cozy/`; подключение из обоих стилей идёт через общий `server_connection_actions.dart`. Окно «Что нового» с выбором стиля → `whats_new_dialog.dart`. Настройки сгруппированы.

### Марсик
- **Диагностика зависшего подключения** → через 10 с: TCP к `ya.ru` / `77.88.8.8`; TCP к серверу (таймаут или отказ); TLS с SNI сервера и ALPN `h2`/`http/1.1` (сервер TrustTunnel без предупреждения рвёт чужой SNI и неподходящий ALPN, поэтому только TLS-alert считается «ответил»); при обрыве — тот же SNI на `ya.ru` с контрольным рукопожатием (отличить блок по SNI от блока IP); затем настоящий `CONNECT` с логином (ответ 403/404/405/407 = ключи не подошли, иначе приняты) — только серверу с проверенным сертификатом; затем подписка (404 = доступ закончился; не чаще раза в 5 минут). Работает во время подключения, потому что нативный сервис исключает само приложение из туннеля → `lib/feature/vpn/domain/connection_diagnostics.dart`, `connection_watchdog.dart`.
- **Поглаживание, комплименты, мурлыканье** (звук не отбирает аудиофокус у музыки) → `lib/feature/companion`.

### Безопасность
- **Строгая проверка сертификата сервера** → нативный движок без сертификата в конфиге проверяет сервер через хранилище Android, куда входят и установленные вручную сертификаты (в том числе Минцифры); если сертификат в конфиге есть — только по нему. Поэтому серверу без своего сертификата приложение подставляет системные корни без «Russian Trusted» → `endpoint_ca_resolver.dart`, `SecurityChannel.kt`; то же правило для проверок из приложения → `server_tls.dart`.
- **Логи** → адрес подписки печатается только хостом, санитайзер вырезает `/api/ct/…` и `AGE-SECRET-KEY-1…` → `trust_tunnel_sensitive_data_sanitizer.dart`.
- **Резервные копии** → запрещены облачные копии и перенос на другой телефон → `AndroidManifest.xml`, `res/xml/data_extraction_rules.xml`.
- **Журнал соединений** → в папке, не попадающей в копии, стирается при запуске приложения и при любом отключении VPN → `plugins/vpn_plugin/.../NativeVpnImpl.kt`.
- **Телеметрия ML Kit** → из манифеста убран транспорт отправки; библиотека в этом случае удаляет события → `AndroidManifest.xml`.
- **Защита экранов с ключами от скриншотов** (FLAG_SECURE) → `lib/widgets/secure_screen.dart`.
- **Проверка телефона, проверка утечек** → `lib/feature/security` + `SecurityChannel.kt`; адрес выхода — `CONNECT 1.1.1.1:80` через сервер и `/cdn-cgi/trace` (само приложение идёт мимо туннеля, поэтому напрямую адрес выхода не узнать).
- **Тревожная кнопка** → системная очистка данных приложения (`clearApplicationUserData`). **Маскировка** → два `activity-alias` (стандартный называется как в 1.2.0 — ярлыки на рабочем столе не пропадают при обновлении). **Блокировка** → `local_auth` поверх всего навигатора, чтобы закрывать и диалоги.

3. Попробуй другой сервер.
